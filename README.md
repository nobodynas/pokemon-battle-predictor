# pokemon-battle-predictor
A Pokemon battle predictor based of the Pokemon television and video game series, made using data science techniques

**Link to live site:** https://pokemon-battle-predictor-8e6ozssvexvkgmme6c2st8.streamlit.app/

**Instructions:**
- Select pokemon 1 from the dropdown menu
- Select pokemon 2 from the second dropdown menu
- You can view each pokemons stats from their respective "View Stats" dropdown
- Hit the "Predict Winner" button whenever you have selected both pokemon you want to battle
- The app will display the winner and the winning chance for each pokemon
- Have fun battling!
